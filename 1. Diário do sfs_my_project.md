## O que aprendi

### Git

- Criar um repositório com `git init`.
-  Verificar alterações com `git status`.
-  Adicionar arquivos com `git add`.
- Criar commits com `git commit`.
- Enviar alterações para o GitHub com `git push`.

### GitHub

- Criar um repositório.
- Conectar o repositório local ao remoto.
- Publicar commits.
- Organizar o projeto online.

## Problemas encontrados

### ⛔ 1. Erro

Renomeei uma imagem `.jpeg` para `.png`.

**Resultado:**

O Git aceitou. ✅

O GitHub não conseguiu renderizar a imagem porque o arquivo ainda era JPEG internamente. ❌

**Solução:**

Verificar usando:

`file prototype.png` 

Assim que descobri o erro, baixei o `ImageMagick`

Depois converti o modelo da imagem, usando ImageMagick.


---

### ⛔ 2. Erro

Pastas vazias não aparecem no Git.

**Solução:**

Adicionar arquivos dentro delas.


---

### ⛔ 3. Erro

Modificar uma `tag` do mod fez todas as texturas desaparecerem dentro do jogo.

**Conclusão:**

Alterar apenas o nome de um arquivo de textura remove somente aquela textura do jogo.

⚠️ Não é recomendado modificar as tags em um mod de textura.
